Production Architecture & Scale Strategy

Blueprint to scale from 1,000 to 500,000+ multi-dimensional records with zero manual intervention.

Download architecture.pdf (3 Pages)

1. 500k+ Scale Strategy

• Distributed Frontier Queue: Apache Kafka partitioned by target domain hash (hash(host) % N) to isolate domain throttling.
• Anti-Bot Navigation: TLS impersonation using curl_cffi (JA3/JA4 Chrome fingerprints) and residential proxy pool rotation to bypass Cloudflare Turnstile & Datadome.
• SPA Engine: Playwright Headless worker pool intercepting raw GraphQL/XHR JSON endpoints directly.

2. Handling 413s & 429s

• HTTP 413 Mitigation: Strips non-semantic DOM tags and enforces sliding token budgeting with sentence boundary lookback.
• HTTP 429 Mitigation: Exponential backoff with Decorrelated Full Jitter (delay = Uniform(0.5, 1.5) * min(30s, base * 2^attempt)).
• Multi-Tier Cascade: Gemini Flash ➔ Groq Llama 3 ➔ DeepSeek ➔ Local Regex Parser.

3. Freshness & Deduplication

• Distributed Bloom Filter: RedisBloom checks seen URLs in <1ms with <0.01% false positive rate across crawler nodes.
• SimHash Content Fingerprinting: 64-bit MinHash detects syndicated cross-posts across different domains (Hamming Distance ≤ 3).
• Strict 24h Verification: Real-time date normalization engine filters out stale news and job records.

4. Polyglot Storage Architecture

• PostgreSQL 16: ACID state of truth for canonical entities and resolution mappings.
• ClickHouse: Ingests 250k+ signal rows/sec with 80% columnar compression for 24h news, jobs, and time-series star metrics.
• Neo4j Knowledge Graph: Constant-time $O(1)$ relationship traversal across complex venture links (Startup ➔ Product ➔ Paper ➔ Repo).
